# /audit - 安全审计命令

对指定文件或整个项目进行安全审计。

## 使用方式

```
/audit [文件路径|--all]
```

## 功能说明

调用安全审计 Agent 进行全面的安全检查，包括：
- OWASP Top 10 漏洞扫描
- 输入验证检查
- 认证授权检查
- 敏感数据保护检查
- 安全配置检查
- 依赖漏洞检查

## 参数

- `文件路径`：审计指定文件
- `--all`：审计整个项目

## 示例

```
/audit src/controllers/task.controller.ts
/audit --all
```

## 输出

生成安全审计报告，按风险等级列出发现的问题和修复建议。
