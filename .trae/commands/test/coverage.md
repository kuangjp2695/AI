# /test/coverage - 查看测试覆盖率

运行测试并生成覆盖率报告。

## 使用方式

```
/test/coverage
```

## 功能说明

运行全部测试并生成详细的覆盖率报告，包括：
- 语句覆盖率
- 分支覆盖率
- 函数覆盖率
- 行覆盖率

## 执行命令

```bash
npm test -- --coverage
```

## 输出

- 控制台输出覆盖率摘要
- `coverage/` 目录下的详细报告（HTML 格式）
- 覆盖率阈值检查结果

## 覆盖率要求

| 指标 | 最低要求 |
|------|---------|
| 语句覆盖率 | ≥ 80% |
| 分支覆盖率 | ≥ 75% |
| 函数覆盖率 | ≥ 80% |
| 行覆盖率 | ≥ 80% |
